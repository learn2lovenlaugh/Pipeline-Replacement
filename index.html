1. Pipeline inputs

Input guidance
  • Corrosion rate per feature = (nominal WT - remaining wall) / (ILI date - install date). Linear, full-life average. Mill defects are not grown unless checked.
  • Design factor F: Psafe = F x Pf, ERF = MAOP / Psafe. Use the class location design factor (0.72 Class 1 gas / B31.4 liquid) or your company factor.
  • Life criterion: Repair = years until ERF reaches 1.0 or depth reaches 80% WT (B31G limit) - use for planning. Failure = years until burst pressure drops to operating pressure or the feature goes through-wall.
  • Coverage basis: Axial projects every failing feature onto the joint axis regardless of clock position and takes the union of their lengths / joint length (needs the distance-from-weld column; otherwise sum of lengths, flagged ~). Area = sum(L x W) / (joint length x pi x OD).
  • Only features that fail the life criterion within Y years count toward coverage.

Method and assumptions

Modified B31G (default): z = L²/(D t); M = sqrt(1 + 0.6275z - 0.003375z²) for z ≤ 50, else 0.032z + 3.3; flow stress = SMYS + 10 ksi; burst strength Sf = Sflow (1 - 0.85 d/t)/(1 - 0.85 (d/t)/M); burst pressure Pf = 2 Sf t / D. Original B31G: Sflow = 1.1 SMYS, M = sqrt(1 + 0.8z), 2/3 dL area; z > 20 uses Sf = Sflow (1 - d/t).

Psafe = F x Pf; ERF = MAOP / Psafe. ERF@Y uses depth grown to as-of + Y.

Remaining life: depth grows linearly at the feature CR, length held constant. The depth at which ERF = 1 (capped at 80% WT) or Pf = OP (capped at 100% WT) is solved by bisection; RL = (d_crit - d) / CR, reported from the assessment date (negative = overdue).

Leak vs rupture: when the remaining ligament fails, the resulting through-wall slot of length L is stable (leak) if OP < Pf_tw = 2 t Sflow / (D M), Sflow = SMYS + 10 ksi, Folias M as Modified B31G. Lcrit solves Pf_tw = OP; L < Lcrit = leak potential, L ≥ Lcrit = rupture potential. Lcrit uses each feature's nominal WT.

Clusters: the reported envelope length and max depth are assessed as one feature (conservative vs RSTRENG). Overlapping features are merged for axial coverage; area coverage simply sums (capped at 100%).

Limits: B31G is valid for d/t ≤ 0.8 and blunt metal loss under hoop stress; no ILI tool tolerance applied; full-life average CR ignores CR changes and initiation time (conservative early, possibly non-conservative if corrosion accelerated recently). Not a substitute for an API 579 Level 2 / RSTRENG effective-area assessment on critical features.
